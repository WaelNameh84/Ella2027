# Ella Local GPU Worker

خدمة وسيطة تربط Ella2027 مع ComfyUI API. هذه الخدمة لا تتضمن نماذج فيديو أو أوزان GPU أو Workflow جاهزاً؛ يجب توفيرها من مشغّل ComfyUI.

## التشغيل

1. شغّل ComfyUI مع API على شبكة يمكن للـWorker الوصول إليها.
2. صدّر Workflow من ComfyUI بصيغة API JSON وضعه في `workflows/video_api.json`.
3. أنشئ رمزاً عشوائياً طويلاً في `ELLA_WORKER_TOKEN`.
4. اربط متغيرات `COMFYUI_*_NODE` بمعرّفات العقد وأسماء مدخلاتها الحقيقية في الـWorkflow.
5. اربط مجلد بيانات دائم على `/data` حتى تبقى سجلات المهام بعد إعادة تشغيل الحاوية.
6. شغّل الخدمة على المنفذ 8090.

## الواجهات

- `GET /health`: فحص غير حساس؛ يعرض إن كان ملف Workflow موجوداً وصالحاً فقط، ولا يثبت أن GPU أو النموذج يعملان.
- `GET /v1/capabilities`: يتطلب Bearer token ويعرض الجاهزية.
- `POST /v1/videos`: يتطلب Bearer token، ويرسل Workflow إلى ComfyUI، ويعيد job ID.
- `GET /v1/jobs/{id}`: يستعلم عن الحالة من ComfyUI مع حفظ سجل المهمة في SQLite.
- `GET /v1/jobs`: قائمة آخر المهام.

## الاستمرارية والسلامة

- بيانات المهام محفوظة في SQLite، وليست في ذاكرة العملية.
- لا يُقبل طلب توليد إذا كان Workflow أو ربط العقد ناقصاً.
- لا تُسجّل مفاتيح أو رموز الوصول في قاعدة البيانات.
- لا تعتبر حالة `generation_ready=true` دليلاً على نجاح توليد فعلي؛ يلزم اختبار توليد كامل على جهاز GPU.
- لا تضع الخدمة مباشرة على الإنترنت دون HTTPS وجدار حماية ورمز قوي.
